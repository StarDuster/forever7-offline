# Current offline features

This is the current offline implementation layer, using the fixed Project7
backend through `project7_bridge`.

- Inventory editing and edit receipts.
- Collection initialization, visibility, and capacity rules.
- Wish/draw business, probability catalogs, and UI projections.
- Mainline/story city/mission rules and data.
- Resource initialization/import/snapshot and single-package startup.
- Automatic login and tutorial UI.

Java package names and embedded Python2 module names are unchanged.
